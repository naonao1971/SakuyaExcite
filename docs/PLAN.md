## ひとことで
⌐◨-◨ バイクで和風の山道を駆け、ターボの熱と空中の傾きを見極めながら CNP 11体を拾い、山頂の鳥居を目指す横スクロールのモトクロス。

## 遊び方
- 目的: 4つのコース（竹林 → 棚田 → 峠 → 山頂の鳥居）を、それぞれ制限時間内に走り抜ける。途中で CNP を拾う
- ミス:
  - 転倒（前輪から着地、ライバルの後輪に接触、障害物に衝突）→ 数秒のタイムロス
  - 熱ゲージが赤まで上がる（オーバーヒート）→ 数秒止まる
  - 制限時間切れ → ゲームオーバー
- クリア: 4コース目のゴール（山頂の鳥居）
- 1プレイの長さ: 3分くらい（1コース40〜50秒）
- 難しさ: だんだん難しく。1コース目はライバルなしの練習、後のコースほどジャンプ台・ぬかるみ・ライバルが増える

## 操作
| | PC | スマホ（横持ち） |
|---|---|---|
| レーン移動（上下） | ↑↓ / W S | 左半分のスティック |
| 空中の傾き（左右） | ←→ / A D | 左半分のスティック |
| アクセル | X | 右下の〇（主ボタン） |
| ターボ（速いが熱が上がる） | Z | 右下の2つ目のボタン |
| 一時停止 / 音 / 自動アクセル | P / M / V | 画面中央 / 🔊 / 自動アクセルの切り替え |

- 自動アクセル: アクセルを押しっぱなしにする切り替え（スマホでは既定でオン）

## CNP 11体
- 出し方: コース上（レーンの上やジャンプの頂点）に置く。4コースに 3・3・3・2 体
- 全員そろえたとき: 大きなボーナス。ロスター（上段中央）が埋まっていくのを見せる

## スコア（目安。仕上げの段階で確定する）
- 何で点が入るか:
  - CNP を拾う: 1体 1,000
  - きれいな着地（両輪そろえて着地）: 200
  - ライバルを転ばせる / 追い抜く: 300
- ボーナス:
  - コースを抜けたときの残り時間: 1秒 100
  - CNP 11体そろい: 10,000
- 理論上の最高点（目安）: 約 43,000 → `maxScore`: 50,000（仮）

## 演出・素材
- キービジュアル: あとで用意（それまではタイトル画面の canvas を書き出して仮に使う）
- クリア動画 / ゲームオーバー動画: あとで用意（無くてもジングルと結果画面は出る）
- BGM: なし（効果音のみ）。エンジン音・ターボ音・着地音はこのゲームだけの音として自前で作る

## kit の設定（決まったら書く）
- controls: `stick: true`（左半分）、ボタン2つ `accel`（X, primary）・`turbo`（Z）、`autoFire: { button: "accel" }` で自動アクセル
- 熱ゲージ: `kit.hud` のゲージ（右上）
- lives: 使わない（ミスはタイムロス、時間切れで終わり）
- hiScoreKey / maxScore: `excite` / 50000（仮）
- ランキング: 総合ランキングに入れる。`kit.gameOver({ score, cleared, rescued, progress })`（progress はコース数 × 25）
- cutscenes / resultScreen / share: 動画は後から。結果画面にボーナスの内訳と拾った CNP、シェアは `https://excite.naoblock.jp/`
