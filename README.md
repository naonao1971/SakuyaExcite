# 咲耶エキサイト（SAKUYA EXCITE - RIDE FOR 11 CNP -）

⌐◨-◨ バイクで和風の山道を走り、4つのコースを制限時間内に抜けて山頂の鳥居を目指す、エキサイトバイク風の横スクロール・モトクロス。
コース上の CNP 11体を拾い集める。咲耶シリーズ（CNP 二次創作・非公式ファンアート）の新作。

- 公開 URL（予定）: https://excite.naoblock.jp/
- 企画書: [docs/PLAN.md](docs/PLAN.md)

## 遊び方

- 4コース（竹林 → 棚田 → 峠 → 山頂の鳥居）を、それぞれ制限時間内に走り抜けるとクリア。時間切れでゲームオーバー
- ターボは速いがエンジンが熱くなる。熱ゲージが赤まで上がると数秒止まる
- 空中では車体を傾けて、両輪そろえて着地する。前輪から落ちたりライバルの後輪に当たったりすると転倒してタイムロス
- CNP 11体を全員拾うと大きなボーナス

## 操作

| | PC | スマホ（横持ち） |
|---|---|---|
| レーン移動（上下） | ↑↓ / W S | 左半分のスティック |
| 空中の傾き（左右） | ←→ / A D | 左半分のスティック |
| アクセル | X | A |
| ターボ | Z | B |
| 一時停止 / 音 / 自動アクセル | P / M / V | ⚙ の設定（自動アクセルは「自動連射」の行） |

## sakuya-kit を使っている

コントローラー、ポーズ、スタート、縦持ち案内、スコア登録とランキング、CNP キャラ、結果画面と演出動画、全画面、効果音、シェアは
[sakuya-kit](https://github.com/naonao1971/sakuya-kit) の共通部品を使う（`index.html` で版 0.6.3 を固定して CDN から読む）。機内モードでも遊べる（`sw.js`、オフライン対応）。
このリポジトリに書くのは、ゲーム本体（`onStart` / `update` / `render`）と、このゲームだけの絵・音・演出。
